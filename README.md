# S2M SBC Integration

Scout2Map UGV의 SBC(Raspberry Pi 5) 소프트웨어 통합 저장소입니다.

이 저장소는 ROS 2 Jazzy 기반 bringup, SLAM/Nav2 설정, 센서 브리지 연동,
Raspberry Pi 설치·점검 도구를 한곳에서 관리합니다.

## 관련 저장소

- [S2M-Hardware](https://github.com/Scout2Map/S2M-Hardware): UGV URDF/Xacro와 Gazebo 자산
- [S2M-MCU_Bridge_Node](https://github.com/Scout2Map/S2M-MCU_Bridge_Node): Pico 센서 USB CDC 브리지
- [S2M-FW-DrivingControl](https://github.com/Scout2Map/S2M-FW-DrivingControl): STM32 주행 제어 펌웨어
